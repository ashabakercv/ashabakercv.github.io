## Local viewing
Serve the repository root over HTTP and open `index.html`. There is no build step, package installation, external font dependency, analytics or API key. Example: `python3 -m http.server 8000` then open `http://localhost:8000/`.

## Publishing
This repository is prepared for GitHub Pages with the `main` branch and repository root as the publishing source. The `.nojekyll` file keeps the committed static files intact. Enable Pages in the repository settings after publishing the source. The desired account is `ashabakercv`.

## Content and maintenance
Use the source data alongside the metric definitions when reviewing the reporting demonstration. The AI evaluation lab uses prepared fixtures, not live model output. The SharePoint/Power Automate example is a browser simulation and deployment design, not a tenant-deployed system. No personal or employer operational records are included in the new demonstrations.
